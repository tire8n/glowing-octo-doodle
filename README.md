# glowing-octo-doodle

A simple, responsive calculator built with HTML, CSS, and JavaScript. No build tools or dependencies are required.

## Run it

Open [`index.html`](index.html) in a web browser.

## Features

- Addition, subtraction, multiplication, and division
- Decimal numbers, sign toggle, and backspace
- Keyboard input support
- Responsive layout
- Division-by-zero handling

## Keyboard shortcuts

| Key | Action |
| --- | --- |
| `0`–`9` | Enter a digit |
| `+`, `-`, `*`, `/` | Choose an operation |
| `.` or `,` | Enter a decimal point |
| `Enter` or `=` | Calculate |
| `Backspace` | Delete the last character |
| `Escape` or `Delete` | Clear |
